# Reset Radar

Made by Aris · © 2026 Aris

Reset Radar is a Windows companion for Codex: view usage and reset information, receive reminders and configure scoped Stop/Resume automation after account confirmation and activation checks.

**Windows x64 · English / Ελληνικά**

This repository contains distribution information and release downloads. The application source is maintained separately and is not published here.

## Downloads and updates

Use **Releases** for published installers and their release notes. Reset Radar's App updates screen checks this repository for newer stable versions, displays changes and download size, and offers Install now or Later. Updates wait for active work and require a verified publisher signature. An unsigned copy requires a normal installation of the first signed release before automatic installation can be enabled.

No signed release is currently available. A prepared unsigned candidate does not establish a verified publisher identity. Do not treat the author label as a digital signature.
